# LMS Manual Testing Project

Manual Testing Project for a Learning Management System (LMS) using Moodle.

## Project Overview
This project demonstrates manual software testing of Moodle LMS from a student perspective. The testing covers core functionalities including login, course access, navigation, activities, grades, and quizzes.

## Testing Scope
- Login with valid credentials
- Login with invalid credentials
- Login validation with empty fields
- View available courses
- Access enrolled courses
- Navigate through course content
- Complete course activities
- View grades
- Access quizzes
- Start and answer quizzes
- Submit quiz attempts
- View quiz results and feedback
