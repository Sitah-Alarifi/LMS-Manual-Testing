# Moodle LMS Manual Testing - Test Plan

## 1. Project Overview
This project focuses on manual functional testing of the Moodle Learning Management System (LMS). The purpose is to validate key student functionalities and ensure that the main features work as expected.

## 2. Testing Objectives
- Verify the login functionality using valid and invalid credentials.
- Validate required login fields.
- Verify course navigation and course access.
- Validate activity completion functionality.
- Verify access to grades.
- Test access to quizzes and assessments.
- Verify quiz attempt, submission, and result functionality.

## 3. Scope

### In Scope
- Login functionality
- Login field validation
- Course viewing and navigation
- Activity completion
- Grade viewing
- Quiz access
- Quiz attempt
- Quiz submission
- Quiz results

### Out of Scope
- Performance testing
- Security testing
- Database testing
- API testing
- Administrator and instructor functionalities

## 4. Test Environment
- Application: Moodle LMS Demo
- Testing Type: Manual Testing
- User Role: Student
- Platform: Web Application
- Browser: Google Chrome

## 5. Testing Approach
Functional testing was performed manually using predefined test cases. Both positive and negative scenarios were executed, and screenshots were captured as test evidence.

## 6. Test Scenarios
A total of 12 test cases were executed covering:
- Authentication
- Field validation
- Course navigation
- Activity completion
- Grades
- Quiz access and execution
- Quiz submission and results

## 7. Entry Criteria
- Moodle LMS Demo is accessible.
- Student account is available.
- Required course content is available.

## 8. Exit Criteria
- All planned test cases are executed.
- Actual results are documented.
- Test evidence is captured.
- Test execution status is recorded.

## 9. Deliverables
- Test Plan
- Test Cases
- Test Execution Results
- Screenshots / Test Evidence
- Defect Report
- Project README
